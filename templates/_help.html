{# Contextual help affordance. The explanation is rendered into the page as escaped text at request time and simply revealed by a class toggle. There is no fetch, no template string, and nothing assigned to innerHTML — the body arrives as a Jinja-escaped text node like every other value on this site. `suffix` disambiguates ids when one topic is referenced twice on the same page. #} {% macro help(topic, suffix='') %} {%- set entry = help_topics.get(topic) -%} {%- if entry -%} {%- set panel_id = 'help-' ~ topic ~ suffix -%} {{ entry.title }} {{ entry.body }} {%- endif -%} {% endmacro %}
