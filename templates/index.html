Defense-only. No control in this interface can block, hold, or cancel a payment, and the system executes no financial action of any kind. A decision recorded here updates a status field and appends one row to an immutable audit log — nothing is ever deleted or overwritten. The model scores and explains; the reviewer decides.

Proof-of-concept. Creates one ₹1 order against Razorpay in test mode and opens their hosted checkout. The signed webhook that the payment produces is verified and enqueued below as an unscored item. The fraud model does not score it: it was trained on the IEEE-CIS feature space, which a payment webhook does not contain, so any number shown would describe placeholder values rather than the payment.

Recorded decisions

Every resolution written to the append-only audit log, newest first. Rows are never edited or removed; a correction is a new row.

Counts and scores on this page are read from the review-queue database this instance is serving. Ground-truth fraud labels are deliberately not present in that database, so the console shows a reviewer exactly what a reviewer would see.
